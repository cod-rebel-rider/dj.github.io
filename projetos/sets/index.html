// Sets · prática

Sets autorais

Sets próprios: não uma lista de músicas, mas uma estrutura flexível de apresentação.

// Método

Como um set é montado

Isso veio do primeiro show solo e está no caderno de aprendizados.

Preparar um set de 1 hora é diferente de montar uma playlist de 1 hora. Durante a apresentação podem acontecer imprevistos, mudanças de clima do público, problemas técnicos ou simplesmente a necessidade de mudar o ritmo planejado.

Por isso o set trabalha sempre com margem de segurança: músicas coringa, alternativas para diferentes momentos e liberdade para antecipar ou atrasar qualquer música.

// O que um set carrega

  • Músicas coringa para mudanças de direção;
  • Músicas extras além do tempo previsto;
  • Alternativas por momento da noite;
  • Organização para achar rápido uma saída;
  • Roteiro definido, execução adaptável.
