// Grimório digital · documentos do projeto

Caderno de campo, aberto

Tudo o que este projeto sabe sobre si mesmo está escrito em arquivos Markdown dentro do repositório — e publicado aqui. Não é bastidor editado: são os documentos como eles são, inclusive as partes incompletas.

Como funciona

Cada página deste grimório é gerada a partir do arquivo .md correspondente. O Markdown é a fonte de verdade: o HTML é só a leitura dele.

Depois de editar um documento, rode python3 tools/build_grimorio.py para regerar as páginas.
